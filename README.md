## Overview
react를 이용하여 개발한 원그로브몰 CMS 입니다. 🙂 <br/>


- 원그로브몰 CMS는 원그로브몰 운영을 위한 관리자 시스템으로, React 19 및 Vite 개발 환경을 기반으로 구축된 SPA(Single Page Application) 형태의 웹 애플리케이션입니다.
- 관리자가 캘린더, 예약, 콘텐츠, 사용자 인터페이스 등을 직관적으로 제어할 수 있도록 구성되었으며, 다양한 UI 컴포넌트와 실시간 인터랙션 기능이 반영되어 사용성과 생산성 모두를 고려하여 구축되었습니다.
- 기획자, 디자이너, 백엔드 개발자와의 협업을 위해 Figma, 메신저, 정기 회의 등 다양한 협업 툴을 적극 활용하였으며, 실무 협업 경험을 쌓을 수 있었습니다.
- TailwindCSS, clsx, class-variance-authority 등을 활용해 반응형 UI를 구현하였으며, React Router v7와 Zustand를 사용해 효율적인 라우팅 및 상태 관리를 구성하였습니다.
- React Hook Form + Zod를 통한 폼 유효성 검증 로직을 설계하고, Axios 기반의 API 통신, JWT Decode, js-cookie 등을 활용한 인증 처리도 직접 구축하였습니다.
- 현재 해당 프로젝트는  실사용 중이며, 실시간 피드백을 바탕으로 기능 개선과 유지보수까지 전담하여 진행중에 있습니다.
- 해당 프로젝트의 메인 개발자로서 전체적인 부분을 구축하고 개발하였고, JavaScript 전반에 대한 이해를 심화할 수 있었고, API 구성, 환경 변수 관리, 서버 사이드 렌더링 등의 심화 지식도 다질 수 있었습니다. React.js에 관해서는 한층 더 성장할 수 있었습니다.
- 해당 프로젝트의 서비스 오픈까지의 여정을 함께하며 프로젝트의 주축을 맡았던 개발자로서의 책임감과 성취감을 확실하게 체감했으며, 개발자로서 성장 가능성을 스스로 기대해볼수 있는 계기가 되었습니다.
